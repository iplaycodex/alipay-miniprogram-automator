### 本次失败原因与修复

此前的失败发生在不同阶段，不能统一归因为 TypeScript 迁移或服务不可用：

- IDE 导入表单虽显示“小程序”，默认导入曾打开 Unity 小游戏类型，模拟器显示基础库 2.1.57。适配器现在通过真实指针事件显式切换并选中支付宝小程序，再确认导入；原生及业务回归均断言实际基础库为 2.10.15。此适配依赖 IDE 3.10.5 的导入界面。
- macOS 临时目录的 `/var/...` 别名曾触发 IDE 构建错误 `CE1000.01: 'unknown' is outside of the project`。SDK 现在先用 realpath 解析项目根目录；原生 E2E 增加通过符号链接路径启动的覆盖。
- 业务默认首页有自动跳转及权限流程。外部回归在独立编译产物副本中新增原生测试引导页，然后进入目标页面；app.js、业务页面及接口实现保留原样。通用准备脚本见 `examples/real-project-e2e`，不改变 SDK 默认启动页面。
- 原用例仅等待门店 25 秒，而真实请求配置的超时为 100 秒。回归改为最多等待 110 秒，检查真实门店内容就绪；此前诊断观察到实际门店请求返回 HTTP 200、业务码 0 和有效数据。
- 首次定位弹窗会遮挡金额按钮。用例按实际 DOM 对“拒 绝”文字去空白后匹配，在初始化等待及交互前显式点击拒绝；保留 SDK 的遮挡检查，不自动授权或修改平台 API。

本轮独立消费工程使用正常 npm 安装的修复包及 Jest 27，沿用原生测试引导页的隔离副本，32.4 秒完成 14/14，基础库 2.10.15。没有 Inspector 外部补丁、请求观察器或 mock 响应，生成了固定金额、自定义弹窗、自定义金额及非法金额等 5 张截图。这里只证明该环境下目标页支付前行为通过，不覆盖首页启动、登录、正式插件或真实支付。早期日志中的 TLS 握手失败和网络服务重启未被证明是独立根因，不据此判定服务端故障。

## 页面与导航审查修复

- 逻辑层通过 `$id` / `$viewId` 对应官方 IDE 的页面 iframe，另用渲染文档身份区分重建。同路径打开多个页面时，Page 查询仅访问该实例的文档；后台页面不会混入当前结果，旧 Page 操作会明确失败。
- `page.query` 使用支付宝页面的 `getLoadOptions()`，不再读取微信式的 `options` 字段。验证覆盖中文参数、真实点击导航、返回以及新建 connect 会话。
- navigateTo、reLaunch、navigateBack 等待原生 success/fail 结果，再验证预期页面栈与实例变化。不存在的页面会报告平台导航失败，不会返回旧页面冒充成功。
- 启动与导航前等待逻辑层和渲染文档一致，并检查 IDE 启动状态。新增两次独立用户目录的冷启动测试，launch 返回后立即导航，不由测试脚本添加启动 sleep。

这些检查修复了审查时“画面为 43、查询却为 41”、同路径导航早于入栈返回，以及 page.query 为空的可复现场景。仍不据此承诺其他 IDE/基础库版本或无限次数冷启动可靠性。

在独立消费目录中安装 `npm pack` 产物也经过验证；npm 包只携带 SDK、文档及许可证。克隆仓库可获得可执行示例和测试。安装方式与使用要求见 README。

## 运行边界与已知限制

- 使用官方 IDE 模拟器运行支付宝小程序产物，没有重新编译成 H5，没有使用 minidev Web、Computer Use、物理手机或 Android 模拟器。
- IDE 自身使用 WebView/DOM 渲染是其内部实现。本 SDK 查询这层实际渲染结果，逻辑求值则进入官方小程序 worker；这不等于浏览器中运行 H5 构建。
- **测试需串行运行。** 同机并发启动两个实验实例时曾出现模拟器目标失效；单实例串行重跑通过。`--user-data-dir` 不足以证明 IDE 的全部全局服务和缓存已经隔离，目前不支持并发实例的可靠性承诺。
- SDK 使用 IDE 内部调试接口，默认只接受上述验证过的 IDE 版本。未知版本可以显式尝试，不能据此认定兼容。
- 截图捕获当前画面，不会自动判断业务完成。小程序逻辑层的路由更新可能早于官方 IDE 导航动画结束，测试应等待相应渲染状态；示例截图在返回动画后捕获并进行人工图像检查。
- 未验证 Windows、Linux、Node.js 22、无桌面 CI、多点触摸、复杂滚动、跨框架组件选择器兼容性及完整微信 automator API 等价性。
- 不覆盖真机 API 的真实性、登录授权、应用绑定、支付、硬件、正式插件和完整生产环境一致性。官方模拟器缺失或模拟实现的能力不会被本库补齐。
