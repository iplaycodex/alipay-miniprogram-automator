## 如何运行

```bash
npm ci
npm run lint
npm test
npm run test:types
npm run test:package
npm run test:e2e
npm run check:package
```

原生 E2E 会自行启动已安装 IDE，输出 `.artifacts/e2e-report.json` 和 `.artifacts/native-main.png`，随后关闭自己创建的 IDE。启动日志输出到 `.artifacts/ide.log`。这些产物已被 Git 忽略，不应公开包含登录态或访问凭证的日志、用户目录。

在独立消费目录中安装 `npm pack` 产物也经过验证；npm 包只携带 SDK、文档及许可证。克隆仓库可获得可执行示例和测试。本项目尚未发布到 npm registry。

## 运行边界与已知限制

- 使用官方 IDE 模拟器运行支付宝小程序产物，没有重新编译成 H5，没有使用 minidev Web、Computer Use、物理手机或 Android 模拟器。
- IDE 自身使用 WebView/DOM 渲染是其内部实现。本 SDK 查询这层实际渲染结果，逻辑求值则进入官方小程序 worker；这不等于浏览器中运行 H5 构建。
- **测试需串行运行。** 同机并发启动两个实验实例时曾出现模拟器目标失效；单实例串行重跑通过。`--user-data-dir` 不足以证明 IDE 的全部全局服务和缓存已经隔离，目前不支持并发实例的可靠性承诺。
- SDK 使用 IDE 内部调试接口，默认只接受上述验证过的 IDE 版本。未知版本可以显式尝试，不能据此认定兼容。
- 截图捕获当前画面，不会自动判断业务完成。小程序逻辑层的路由更新可能早于官方 IDE 导航动画结束，测试应等待相应渲染状态；示例截图在返回动画后捕获并进行人工图像检查。
- 未验证 Windows、Linux、Node.js 22、无桌面 CI、多点触摸、复杂滚动、跨框架组件选择器兼容性及完整微信 automator API 等价性。
- 不覆盖真机 API 的真实性、登录授权、应用绑定、支付、硬件、正式插件和完整生产环境一致性。官方模拟器缺失或模拟实现的能力不会被本库补齐。
